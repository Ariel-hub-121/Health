# Health+

## Overview

Health+ is a browser-based wellness web app that brings everyday health tools into one calm, easy-to-use space. It includes BMI and TDEE calculators, a health quiz, mood and lifestyle tracking, nearby activity discovery, Google sign-in, and a supportive mailbox experience.

## Live Demo

https://ariel-hub-121.github.io/Health/

## Features

- BMI and TDEE calculator with personalized result feedback.
- Guided health quiz for daily wellness reflection.
- Mood, water, and exercise calendar with monthly chart summaries.
- Nearby sports venue finder powered by Google Maps and Places.
- "Tree hole" mailbox for writing thoughts and receiving supportive replies.
- Google sign-in support through Firebase Authentication.
- Responsive sidebar navigation with a soft, wellness-focused visual style.

## Tech Stack

- HTML, CSS, and vanilla JavaScript
- Chart.js
- Lucide icons
- Google Maps JavaScript API and Places
- Firebase Authentication and Firestore
- Cloudflare Worker endpoint for mailbox replies

## Usage

Open the deployed Health+ website in a modern browser. Some features require internet access, including Google Maps, Firebase sign-in, and the mailbox reply endpoint.

## Notes

- Mood, water, and exercise records are stored in the browser with `localStorage`.
- Health calculations are for general wellness reference and should not replace professional medical advice.
- Client-side API keys and external service settings are restricted for the intended domains and API scopes.
